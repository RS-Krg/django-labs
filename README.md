# Учебные Django-проекты

В этом репозитории собраны три самостоятельных проекта. История коммитов каждого проекта сохранена при объединении.

| Проект | Описание | Запуск |
| --- | --- | --- |
| [helpdesk](helpdesk/) | Учёт заявок ИТ-отдела | [README](helpdesk/README.md) |
| [shop](shop/) | Магазин техники, каталог, корзина и заказы | [README](shop/README.md) |
| [final_project](final_project/) | Итоговый магазин спорттоваров с размерами и отчётами | [README](final_project/README.md) |

Каждый проект запускается отдельно из своей папки. Для локального просмотра выполните команды из соответствующего README. Учебные пользователи и ключи в исходном коде предназначены только для демонстрации; для размещения сайтов в интернете нужны отдельные производственные настройки и учётные данные.
