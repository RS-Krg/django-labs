# Учебные Django-проекты

В этом репозитории собраны три самостоятельных проекта. История коммитов каждого проекта сохранена при объединении.

Исходные задания лабораторных работ находятся в папке [assignments](assignments/). Краткая сводка выполнения — в [PROGRESS.md](PROGRESS.md), заметки для показа — в [DEFENSE.md](DEFENSE.md).

| Проект | Описание | Запуск |
| --- | --- | --- |
| [helpdesk](helpdesk/) | Учёт заявок ИТ-отдела | [README](helpdesk/README.md) |
| [shop](shop/) | Магазин техники, каталог, корзина и заказы | [README](shop/README.md) |
| [final_project](final_project/) | Итоговый магазин спорттоваров с размерами и отчётами | [README](final_project/README.md) |

Каждый проект запускается отдельно из своей папки. Выполните команды из соответствующего README **из корня репозитория**. Если вы уже перешли в папку проекта, пропустите в инструкции строку `cd .\имя_проекта`.

| Сайт | Локальный адрес | Что должно открыться |
| --- | --- | --- |
| `shop` | http://127.0.0.1:8001/ | Магазин компьютерной техники |
| `final_project` | http://127.0.0.1:8002/ | Магазин спорттоваров |
| `helpdesk` | http://127.0.0.1:8003/ | Заявки ИТ-отдела; сначала страница входа |

Чтобы открыть все три сайта одновременно, запустите каждый в отдельном окне PowerShell. Старый сервер на порту `8000` можно остановить сочетанием `Ctrl+C` в его окне. Учебные пользователи и ключи в исходном коде предназначены только для локальной демонстрации.
