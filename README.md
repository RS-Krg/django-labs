# Учебный магазин компьютерной техники — лабораторные №0.2 и №0.3

## Запуск на Windows

```powershell
cd shop
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py runserver
```

Каталог: http://127.0.0.1:8000/. Администратора создают через `manage.py createsuperuser`.
Тесты: `.\.venv\Scripts\python.exe manage.py test`.

Каталог содержит категории, активные товары, фото, поиск по кириллице без учёта регистра, сортировку и постраничный вывод. Корзина хранится в сессии; регистрация и заказы работают через сайт. Менеджер обрабатывает заказы через действия в admin panel. Повторный запуск `seed_demo` не создаёт дублей.

## Демонстрационные пользователи

- `buyer` / `ShopDemo-2026` — покупатель.
- `manager` / `ShopDemo-2026` — менеджер с доступом к товарам и заказам в `/admin/`, без прав суперпользователя.

Для демонстрации найдите «МОНИТОР», добавьте товар в корзину, войдите как `buyer`, оформите заказ и откройте его в личном кабинете. Затем войдите как `manager` в `/admin/`, подтвердите заказ действием списка. Новый заказ нельзя сразу отметить выполненным. Для проверки отката уменьшите остаток после добавления товара в корзину и попробуйте оформить заказ.
